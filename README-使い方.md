# AI・IT 情報キャッチアップ — 使い方

AI・ITの「最新モデル・ツール／トレンド・ニュース／用語のやさしい解説／使ってみるヒント」を
一画面でざっと眺められるダッシュボードです。**情報は毎週月曜の朝、自動で最新化**されます。

> ねらい：AIに必要なのは「30%の好奇心・70%の情報収集」。
> その“探して集めて要約する”手間をこのツールに肩代わりさせ、あなたは気になったものを試すだけにする、という道具です。

---

## 1. 見る（誰でもOK・Claude不要）

1. このフォルダの **`index.html`** をダブルクリック。
   （デスクトップの「AI・IT情報キャッチアップ」ショートカットからでもOK）
2. 上のタブで見たいものを選ぶ：
   - **🏠 今週のダイジェスト** … 注目のニュース・モデル・今週のことばを数件だけ抜粋
   - **🚀 最新モデル・ツール** … 話題のAIを「無料か・初心者向きか」で絞り込み
   - **📰 トレンド・ニュース** … 最近の大きな動きを、専門用語なしで
   - **📖 用語・基礎知識** … 「トークンって？」をやさしく。ここが目玉
   - **💡 使ってみる** … 今日試せる小ネタ／実務での活用ヒント
   - **🆕 新着** … 前回の更新から新しく追加されたものだけ

> インストール不要・ネット接続なしでも閲覧できます（🔗出典リンクを開く時だけネットが必要）。

---

## 2. 情報の自動更新（この仕組みの心臓部）

- **あなたのPC（Claude Code が入っているPC）** が、毎週月曜8:00に自動で公開情報を調べ、
  データ（`data.js`）を最新化します。
- 更新のとき Claude がやることは **「公開情報を読みに行く」だけ**。
  会社の数字や個人情報を送ることは一切ありません（＝情報漏洩リスクを抑えた設計）。
- 「見る人」には Claude は不要です。

### すぐ最新にしたいとき（任意）
- **`今すぐ更新.bat`** をダブルクリック → 数分で最新化 → `index.html` を開き直す。

### 更新の時刻を変える・止める／頻度を増やす
Windowsの「タスクスケジューラ」で **「AI-IT情報キャッチアップ_自動更新」** を探します。
- 時刻変更 … タスクを右クリック →「プロパティ」→「トリガー」
- 一時停止 … 右クリック →「無効」／ 完全に削除 … 右クリック →「削除」
- **頻度を増やしたい**（毎日など）… トリガーを追加できます。声をかけてください。

---

## 3. 大事な注意

- この一覧は **「キャッチアップ用の早わかり」** です。AIが公開情報を集めて要約しています。
- **料金・機能・事実は変わりやすい**ので、実際に使う・判断する前に必ず各カードの
  **「🔗 出典（公式ページ）」** で最新をご確認ください。
- 「用語・基礎知識」は定義のため、出典を付けていないものがあります。

---

## 4. 内容の方針（この案件の決めごと）

- **用語・基礎知識を多めに**育てる（ITリテラシーの底上げが目的）。
- **最新モデル・トレンドも多めに**。
- **会計事務所でのAI活用**は、実在する公開記事・事例が見つかった時だけ掲載（憶測では載せない）。

---

## 5. ファイルの説明（触らなくてOK）

| ファイル | 役割 |
|---|---|
| `index.html` | 見る画面（ダッシュボード）。ダブルクリックで開く |
| `data.js` | データ本体（モデル・ニュース・用語・ヒント）。自動更新で書き換わる |
| `update.ps1` | 自動更新の実行スクリプト |
| `update-prompt.md` | 更新時に Claude が読む指示書 |
| `setup.ps1` / `セットアップ.bat` | 自動更新タスクとショートカットの登録（引っ越し時に再実行） |
| `今すぐ更新.bat` | 手動で今すぐ更新したい時に使う |
| `logs/` `backups/` | 更新の記録と、data.js の自動バックアップ |

---

*このツールは「公開情報を取りに行くだけ」で動きます。実データ（社内情報）を入力する場面はありません。*
